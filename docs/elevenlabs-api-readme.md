# ElevenLabs API 키 · 크레딧 · 테스트 노트북 안내

팀원이 ElevenLabs API로 TTS를 돌리기 전에 읽는 문서입니다. 기존 파이프라인 설명은 `docs/runbook.md`, 실험 설계는 `docs/experiment-design.md`를 참고하세요.

## 1. API 키 다루는 법

- 키는 **코드, 노트북, 문서, 커밋에 절대 적지 않습니다.**
- 환경변수 `ELEVENLABS_API_KEY`에 저장하거나, 노트북 실행 시 입력창(`getpass`)에 붙여 넣습니다.
- `.env`, `.env.local`은 `.gitignore`에 들어 있지만, 키가 든 파일을 새로 만들었다면 커밋 전에 한 번 더 확인하세요.
- 키가 노출된 것으로 의심되면 즉시 ElevenLabs 대시보드에서 폐기하고 새로 발급받습니다.

## 2. 크레딧 구조 (확인된 내용)

대시보드 요금 메뉴에서 확인한 값입니다.

| 항목 | 값 | 비고 |
|---|---|---|
| 워크스페이스 할당량 | 129,926 크레딧 | API 호출은 여기서 차감된 것으로 확인 |
| 워크스페이스 사용량 (테스트 시점) | 6,999 크레딧 | 테스트 1문장 이전 사용분 포함 |
| 기본 좌석 | 좌석당 50,000 크레딧 | API 호출에 쓰이는지는 **미확인** |

- 텍스트 한 문장당 차감은 글자 수 기준으로 봅니다.
- `advbench_ko.csv`의 `goal_ko` 기준: 520문장, **총 18,213자**(평균 35자, 최대 58자).
- 한 언어 clean 1회 = 약 18,200 크레딧. 교란(reverb, echo, whisper)은 로컬에서 계산하므로 크레딧을 쓰지 않습니다.
- 10개 언어 = 약 182,000 크레딧. **워크스페이스 남은 양(약 122,900)만으로는 부족합니다.** 좌석 크레딧이 API에 쓰이는지 확인한 뒤 계획을 확정합니다.
- 본 실험 전에 기존 파일럿(`docs/pilot-2026-09-28.md`)의 사용량도 같은 워크스페이스에서 차감됐는지 확인하세요.

## 3. 테스트 노트북 (`tts_pilot_test.ipynb`)

문장 1개로 **TTS → 장부 → 교란 4개** 흐름이 동작하는지 확인하는 용도입니다. 본 실험용이 아닙니다.

- 입력: `advbench_ko.csv`의 `goal_ko` 첫 행
- TTS: `eleven_multilingual_v2`, `output_format=pcm_16000`, `stability=0.0`, `similarity_boost=0.5`
- 결과: `work_test/audio/{clean, reverb_room, reverb_large, echo, whisper}/test_000.wav`, `work_test/ledger.csv`
- 교란 파라미터는 원 논문 부록 A.1을 따르되, IR 파일이 없어 **합성 IR**을 씁니다. 결과는 조건 간 상대 비교용입니다.

### 기존 파이프라인과 다른 점

팀 파이프라인(`configs/voices_elevenlabs.json`, `docs/pilot-2026-09-28.md`)과 설정이 다릅니다. 본 실험 전에 맞출지 정해야 합니다.

| 항목 | 테스트 노트북 | 기존 파이프라인 |
|---|---|---|
| 모델 | eleven_multilingual_v2 | eleven_v3 |
| 출력 | pcm 16 kHz | pcm 24 kHz |
| 음성 | 1개 (brazilian) | 38개 슬롯 중 31개 |

## 4. 다국어 확장 시 원칙

- 텍스트는 **한국어 원문(`goal_ko`)을 고정**하고 음성 ID만 바꿉니다. 외국 억양으로 한국어를 읽는 조건입니다.
- 결과는 언어별 하위 폴더에 저장하고, 장부(`manifest`)에는 `lang`, `voice_id`, `perturbation` 열을 둡니다.
- 비교는 모든 언어에서 **같은 프롬프트 목록**으로 합니다.
- 교란 정규화(`peak_normalize`)는 모든 언어에 동일하게 적용합니다.

## 5. 아직 정하지 않은 것

- 본 실험 모델·출력 포맷을 기존 파이프라인(`eleven_v3`, 24 kHz)에 맞출지
- 기본 좌석 크레딧이 API 호출에 포함되는지
- 사용할 음성 목록 (어느 언어 몇 개)
